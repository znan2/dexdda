# 대시보드 숨김 관리와 입출금 갱신

2026-09-20 구현. 서버를 재시작한 다음 브라우저를 새로고침하면 적용된다.

## 기본 목록

- 정상 유동성 관측 이력이 없는 경로와 설정한 최소 유동성 미만 경로는 두 탭 모두에서 숨긴다. 포함 체크박스는 제거했다.
- 과거 정상 유동성 값이 있는 경로는 마지막 값으로 최소 유동성 기준을 적용하고 경과 시간을 표시한다.
- 숨겨진 미관측 경로도 백그라운드 조회는 계속한다. 정상값을 받고 표시 기준을 충족하면 자동 복귀한다.
- 기본 목록과 별도의 ‘입금 중단’ 탭으로 분리한다. 같은 코인이라도 거래소별로 나눠 입금 중단인 경로만 해당 탭에 표시한다. 입금 가능한 다른 거래소 경로는 기본 목록에 유지한다. 입금 재개 시 자동으로 기본 목록으로 복귀한다. 중단 탭의 갭은 참고용이며 기존 상세/실행 검사는 그대로 적용한다.
- 출금만 막힌 deposit_only는 매도 입금에 사용할 수 있으므로 유지한다. withdraw_only와 paused는 입금 불가다.
- API 조회 전, 오류, 응답에서 해당 네트워크 누락, 90초 신선도 초과 시 ‘상태 확인 필요’로 표시한다. 확인된 정상인 것처럼 초록색을 유지하지 않는다. 상태 미확인 자체는 코인을 숨기지 않으며 실제 견적은 기존 별도 입금 검사에 따른다.

## 블랙리스트 / 임시 제외

상단 ‘숨김 관리’를 펼쳐 종목을 검색하고 범위·선택적 사유를 입력한다.

- **코인 전체 블랙리스트**: 고유 coin_id로 저장해 같은 티커의 다른 코인과 구분한다. 모든 체인·거래소 후보 및 의심 목록에서 숨긴다.
- **거래소·입금망 임시 제외**: 선택한 코인·거래소·net_type에만 적용한다. 공지를 먼저 확인했지만 API 상태가 늦는 경우에도 직접 제외할 수 있다. 직접 해제할 때까지 유지되며 자동 조회로 덮어쓰지 않는다.
- 코인 전체 블랙리스트와 거래소·입금망 임시 제외는 모두 상단 ‘숨김 관리’에서 추가·해제한다. 목록 행에는 숨김 버튼을 표시하지 않는다.
- 어느 탭에서도 블랙리스트/수동 제외 항목을 다시 표시하지 않는다.
- 동일 코인의 다른 거래소 경로는 별도로 관리한다. 직접 입금 경로는 매수 체인과 매핑된 입금망의 상태로 판단한다. 다른 체인의 입금 가능 상태를 가져와 대체하지 않는다.
- 저장 파일: `data/dashboard_preferences.json`. 원자적 교체와 파일 잠금을 사용하며 서버·브라우저 재시작 후에도 유지된다. 저장 실패 시 성공으로 표시하지 않는다. 테스트는 별도 임시 저장소를 쓴다.
- 코인/직접 입금망을 수동 제외하면 기존 상세 요청과 새 실행 준비에서도 차단한다. 이미 전송된 트랜잭션을 취소하는 기능은 아니다.

## 입출금 조회

- 양 거래소 `/v1/status/wallet`을 서버에서 30초마다 조회한다. 거래소당 한 번에 전체 상태를 받는다.
- 상단 ‘입출금 새로고침’으로 재조회할 수 있다. 동시 요청을 병합하며 10초 이내 반복 클릭은 캐시를 반환한다. 여러 브라우저가 요청해도 각자 별도 폴링하지 않는다.
- 가격/상세 조회와 동일한 거래소 호출 게이트를 사용한다. 오류는 거래소별로 분리해 한쪽 실패가 다른 쪽 갱신을 막지 않는다.
- 상태 키는 거래소·코인 심볼·net_type이며, 표시할 네트워크의 정체성은 기존 검증된 레지스트리를 따른다. 런타임에 신규 네트워크를 임의 거래 경로로 추가하지 않는다.
- 상세 견적에서 받은 최신 전체 wallet 응답도 공유 캐시에 반영한다. 먼저 시작한 오래된 응답이 새 응답을 덮어쓰지 않는다.
- 갱신 시각은 API를 정상 수신한 시각이다. 거래소 자체의 상태 반영이 지연되는 문제까지 해결하는 것은 아니다. 업비트 문서에도 수 분 지연 가능성이 명시돼 있다.
- 기본 설정: `pricing.wallet_poll_seconds=30`, `pricing.wallet_stale_seconds=90`.

## 검증

- Python 256개 테스트 통과: 네트워크 매핑·부분 거래소 실패·만료·복구·중복 조회 병합·쿨다운·영구 저장·동일 티커 구분·저장 실패·로컬 세션/Origin 검사·상세 경로 제외.
- Chrome 합성 검증: 기존 목록·상세·실행·피드백 및 신규 `scripts/check_controls_ui.cjs`.
- 신규 검증: 미관측 제외/입금 중단 별도 탭, 과거 유동성 재사용 유지, FET 상태 수동 갱신 후 숨김, 타 거래소 경로 유지, 블랙리스트 추가/해제/새로고침 유지, 임시 제외 자동 해제 방지, HTML 문자열 안전 표시, 모바일 가로 넘침 없음.
- 실제 읽기 전용 검증에서 FET 빗썸 ETH wallet_state=paused, Ethereum/BSC 후보의 deposit_possible=false를 확인했다. 거래 전송 없이 상태 API만 조회했다.

## 목록 간소화 (2026-09-20)

- 상시 유동성 단위 설명, 숨긴 경로 개수, 세 개의 포함 체크박스를 제거했다.
- 최소 유동성 입력은 0.1~10.0m, 소수점 한 자리로 유지하며 두 탭에 공통 적용한다. 잘못된 값 입력 시에만 안내를 표시하고 직전 유효값을 유지한다.
- 검색·갭 정렬·경로 비교·CA 복사·상세 견적은 현재 탭의 경로에 적용한다.
- 상단 요약 지표는 기본 목록 기준이며, 입금 중단 탭 이름 옆 숫자는 해당 탭의 유동성 기준을 충족한 코인 수다.
- 브라우저 검증 5종 통과: 목록, 숨김 관리/탭 분리와 재개, 상세, 피드백/참고 견적, 로고. 키보드 탭 이동과 모바일 가로 넘침도 확인했다.
- 이번 화면 변경은 브라우저 새로고침으로 적용된다.

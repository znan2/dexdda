# M4 검증 기록

2026-09-20. 상세 패널, 읽기 전용 견적 API, 호가 소진과 비용 반영 실효갭을 구현했다.

## 완료 기준별 근거

| 요구사항 | 검증 |
|---|---|
| 행 선택·금액 입력·거래소 선택 | Chrome에서 클릭/Enter로 열기, 금액 1,000→2,000 변경 및 업비트→빗썸 변경 시 재계산 |
| 부분 호가 소진 | 높은 매수 가격부터 체결하고 마지막 단계 일부만 소비하는 Decimal 단위 테스트 |
| 호가 부족 | 조회된 잔량만 체결 표시, 전량 매도 가능 false, 손익 null |
| 수량·세금·단위 | 최소 단위 정수/decimals, fractional tax와 내림, 잘못된 CA/chain/amount/decimals 거부 |
| 가스비 | swap tradeFee와 approve·전송 1회 비용을 분리. allowance 충분/0/부족에 따른 승인 0/1/2회 검증 |
| 공통 환산 | 빗썸 선택 시에도 업비트 USDT ask 사용, 거래소 매매 수수료 항목 없음 |
| 입금 상태 | 이번 조회에서 wallet 갱신, 업비트 query_hash 및 입금 가능 정보, 중단/최소 수량 미달 시 보류 |
| 위험·실패 | 허니팟, 양수 세율, 가스 누락, RPC 오류, 미검증 매수 자산, 브릿지, stale는 손익 없음 |
| 식별 경계 | 미등록 coin_id/chain/CA는 외부 견적 요청 전에 거부 |
| 오류 표시·재조회 | 합성 429 오류 메시지 후 갱신 복구, 개인키 유사 입력이 API 오류에 반사되지 않음 |
| 응답 경합·만료 | 늦게 온 이전 금액 응답 무시, 만료 손익 숨김, 서버 처리시간 이중 차감 수정 |
| 패널 재열기·키보드 | 늦은 native close 이벤트가 새 조회를 지우던 문제 수정, Esc→Enter 재열기 회귀 검사 |
| 모바일 | 390px 너비에서 문서·패널 가로 넘침 없음, 내용 세로 스크롤 및 비활성 실행 버튼 확인 |
| 기존 기능 | M3 검색·정렬·접기·XSS 문자열 표시·stale·연결 복구·모바일 회귀 검사 |
| 실행 경계 | execution_enabled=false, swap/approve/transfer 라우트 404, RPC 쓰기 메서드 차단 |

## 검증 결과

- Python 테스트 **173 passed** (M0~M3 포함).
- Ruff lint/format, JavaScript 구문 검사 통과.
- M4 오프라인 Chrome 검사 통과, pageerror 0.
- M3 오프라인 Chrome 회귀 검사 통과, pageerror 0.
- 실제 ETH 1,000 USDT 견적을 업비트·빗썸 각각 조회해 quote, 30단 호가, 가스 추정, 실효갭 계산을 확인했다. 두 요청 모두 서비스 오류 목록이 비어 있었다.
- 업비트 ETH에서 36 confirmations, 최소 입금 0.0015 ETH, 최근 블록 기준 432초를 관측했다. 시점에 따라 달라지는 값이며 하드코딩하지 않는다.
- 실제 가격 수집기와 함께 실행한 Chrome에서 ETH 상세 견적·유효 실효갭 표시를 확인했다. 최종 화면 관측값 -0.239%는 검증 시점의 추정이며 거래 기회/수익 보장이 아니다.
- 실제 조회는 공개 시장 데이터, 계정의 읽기 전용 입금 상태, 지갑 allowance/RPC에 한정했다. 개인키 서명, 트랜잭션 전송, 거래소 주문, 주소 생성은 하지 않았다.
- 테스트 서버·브라우저는 각 스크립트의 finally에서 종료한다.

스크린샷을 직접 확인해 데스크톱·모바일의 수량/가스/입금 정보와 버튼 배치를 검토했다.

## 구현 범위의 제한

매수 자산은 공식 주소를 확인한 12개 체인이다. 29개 체인 목록은 유지한다. 완전한 가스 추정은 현재 Ethereum·Polygon·Avalanche C에서 필요한 RPC/지갑 주소가 갖춰졌을 때 제공하며, 그 외에는 추가 체인 비용 검증 전 실효갭을 보류한다.

전송 gas는 설정 예산이며 실제 수신 주소를 사용한 시뮬레이션이 아니다. 빗썸 컨펌 수·최소 입금량 미제공, 업비트 상태 반영 지연, 세금 토큰 전송세 미확인도 표시한다. 상세 설명과 공식 근거는 [사용 안내](m4-detail.md)에 정리했다.

M5 스왑 실행, M6 전체 종목 입금 주소 사전 생성, 유료 API 선택은 이번 작업에 포함하지 않았다.

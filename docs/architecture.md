# Architecture

Package is `src/app` (hatch; `dexdda` entry = `app.main:main`). `PROJECT_ROOT` in `app/config.py` resolves to the repo root, and runtime artifacts live under `data/`.

**Startup / request flow** (`app/main.py`): `create_app()` builds a FastAPI app whose lifespan constructs a `Collector` from `data/registry.json` + settings + credentials, then `DetailService(collector)`, and — only if the collector has a client — `SwapService`, `AddressBook`, and `Operations`. Startup errors are captured as `app.state.startup_error` (`invalid_config` / `internal_error`) and surfaced as 503 rather than crashing. `create_app()` accepts injected services so tests and UI fixture servers can run offline. Execution/preferences/operations routes are in `app/api/execution.py`.

**Layers**
- `app/config.py` — `Settings` (from `config/settings.toml`, pydantic `extra="forbid"`, host locked to `127.0.0.1`) and `Credentials` (read only from `.env` via dotenv, never ambient env; `DRY_RUN` defaults true; `RPC_URL_<chainId>` keys auto-discovered).
- `app/adapters/` — one module per external service (okx, upbit, bithumb, coingecko, rpc, prices, detail, execution). `base.py` defines the `Failure` enum and `AdapterError`; every remote error is classified into a category and **no remote response text is ever propagated** into errors, logs, or API output.
- `app/registry/` — M1. `builder.py` is pure/deterministic (identity = CoinGecko coin ID + chain + contract); `cli.py` fetches sources; `loader.py` reads `data/registry.json` and `config/{chain_map,overrides}.toml`. `chain_map.toml` is the verified exchange `net_type` → `chain_index` mapping (no runtime guessing by display name); `overrides.toml` holds manual identity mappings/exclusions with evidence.
- `app/pricing/` — M2/M3. `Collector` runs bounded background workers (OKX price REST/WS, liquidity, wallet balances) and keeps in-memory `Quotes`/`Clock` state; **API reads never make external requests**, they return the latest snapshot. `gap.py` computes gaps against the Upbit USDT price as the common reference; `filters.py`/`comparison.py` handle low-liquidity hiding and per-coin chain comparison.
- `app/detail/` — M4. `DetailService.calculate()` composes a read-only detailed quote (OKX quote + RPC gas + exchange order book via `math.consume_bids`); `effective_result` is the executable P&L, `reference_result` is the informational one when deposits are suspended.
- `app/swap/` — M5. `SwapService` is a state machine: `/api/swap/prepare` creates a server-owned intent; `/api/swap/confirm` only accepts that intent ID (client cannot alter calldata/amount/nonce). Order is user confirmation → DRY_RUN guard → allowance reset → approve → swap. Router/spender addresses are checked against `config/contracts.json`; tx hash/nonce is persisted atomically **before** broadcast and there is no automatic replay.
- `app/deposit/addresses.py` — M6. `AddressBook` prepares deposit addresses for every tradable exchange/coin/net_type combo into the private `data/deposit_addresses.json`.
- `app/operations.py` — M7. New-listing watch and ECB reference FX; isolated so it can never feed trading inputs. `EventLog` writes `data/operations.jsonl` with enumerated fields only.
- `app/private_store.py` — atomic JSON writes with mode 600 and `fcntl` advisory locks for private files (`deposit_addresses.json`, swap journal, `*.lock`); all are git-ignored.
- `src/app/web/` — vanilla JS/CSS frontend served at `/` and `/assets`; polls `/api/gaps`, `/api/detail`, etc. Styling follows the portfolio DESIGN.md tokens (Korean up/down colors: red `up`, blue `down`).
- **Static demo** — `scripts/build_static.py` runs `create_app()` in-process with synthetic providers (`tests/detail_fixtures.py`, `tests/test_swap.py` fakes plus a demo adapter), captures every response the UI needs into `dist/data/demo.json`, and copies `src/app/web` into `dist/assets/` with `scripts/static/static-api.js`, which answers `/api/*` fetches from that file (timestamps shifted to now). No backend, no outbound requests; CSP is emitted to both `dist/_headers` and a meta tag. Checked by `tests/test_static_build.py` and `scripts/check_static_ui.cjs`.
